# Сокращение URL с поддержкой PostgreSQL

## Описание
Служба для сокращения URL, позволяющая хранить сопоставления между короткими и полными URL. Поддерживает несколько режимов хранения:

1. **PostgreSQL** — основной режим, активируется при указании переменной окружения `DATABASE_DSN` или флага `-d`.
2. **Файл** — резервный режим, активируется при наличии `FILE_STORAGE_PATH` или флага `-f`, если PostgreSQL не настроен.
3. **Память** — режим по умолчанию, используется, если не указаны ни DSN, ни путь к файлу.

## Конфигурация

### Переменные окружения
| Переменная | Описание | Значение по умолчанию |
|------------|---------|----------------------|
| `SERVER_ADDRESS` | Адрес и порт сервера | `:8080` |
| `BASE_URL` | Базовый URL для сокращённых ссылок | `http://localhost:8080` |
| `LOG_LEVEL` | Уровень логирования | `Info` |
| `FILE_STORAGE_PATH` | Путь к файлу для хранения URL | `./short-url-db.json` |
| `DATABASE_DSN` | DSN для подключения к PostgreSQL | `user=postgres dbname=postgres sslmode=verify-full` |

### Флаги командной строки
| Флаг | Описание | Приоритет |
|------|---------|----------|
| `-a` | `SERVER_ADDRESS` | Переменная окружения → Флаг → Значение по умолчанию |
| `-b` | `BASE_URL` | Переменная окружения → Флаг → Значение по умолчанию |
| `-l` | `LOG_LEVEL` | Переменная окружения → Флаг → Значение по умолчанию |
| `-f` | `FILE_STORAGE_PATH` | Переменная окружения → Флаг → Значение по умолчанию |
| `-d` | `DATABASE_DSN` | Переменная окружения → Флаг → Значение по умолчанию |

## Установка и запуск

### Требования
- Go 1.25 или выше
- PostgreSQL (для режима БД)

### Сборка
```bash
go build -o shortener ./cmd/shortener
```

### Запуск с PostgreSQL
```bash
DATABASE_DSN="host=localhost user=postgres password=secret dbname=urlshortener sslmode=disable" ./shortener -a :8080
```

### Запуск с файлом
```bash
./shortener -f ./data/urls.json -a :8080
```

### Запуск в памяти
```bash
./shortener -a :8080
```

## Миграции базы данных
Схема базы данных управляется с помощью миграций. Первая миграция создаёт таблицу `t_urls` и индексы:

- `t_urls` — основная таблица для хранения URL
  - `n_id`: SERIAL PRIMARY KEY
  - `s_long_url`: VARCHAR(1000) NOT NULL
  - `s_short_url`: VARCHAR(50) NOT NULL
- Индексы: `idx_data_full` (по `s_long_url`), `idx_data_short` (по `s_short_url`)

Миграции находятся в директории `migrations/`.

## API
- `POST /` — сокращение URL из текста
- `POST /api/shorten` — сокращение URL в формате JSON
- `GET /{id}` — редирект на полный URL
- `GET /ping` — проверка подключения к БД (доступно только при включённой поддержке PostgreSQL)
